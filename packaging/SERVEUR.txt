NumFranc — installer un NŒUD PERMANENT (serveur)
================================================

À quoi ça sert ?
   Un nœud permanent reste allumé jour et nuit. Les nouveaux utilisateurs le trouvent
   toujours, même quand ton Mac est éteint. Il relaie les blocs et les paiements.
   Il n'a PAS de portefeuille et ne mine pas : même piraté, il n'y a rien à voler.

Deux solutions gratuites
   A. Un vieux PC (ou un Raspberry Pi 4/5) chez toi, branché sur la box, avec Ubuntu.
      Gratuit si tu as déjà la machine. Dépend de ta box et du courant.
   B. Oracle Cloud « Always Free » (serveur gratuit à vie, très fiable et rapide).
      Il faut un compte avec carte bancaire et avoir 18 ans : à faire avec tes parents.
      Choisir Ubuntu, et ouvrir le port TCP 6910 dans la « Security List ».

Installation (Ubuntu, une seule fois)
   1. Copier le dossier NumFranc sur la machine, par exemple dans /home/UTILISATEUR/NumFranc
   2. Compiler :
        sudo apt update && sudo apt install -y build-essential curl
        cd ~/NumFranc && bash lancer-numfranc.sh --aide
   3. Installer le service (redémarre tout seul après une panne ou un redémarrage) :
        mkdir -p ~/.numfranc
        sudo cp numfranc-serveur.service /etc/systemd/system/
        sudo sed -i "s/UTILISATEUR/$USER/g" /etc/systemd/system/numfranc-serveur.service
        sudo systemctl daemon-reload
        sudo systemctl enable --now numfranc-serveur
   4. Vérifier :
        systemctl status numfranc-serveur
        journalctl -u numfranc-serveur -f        (Ctrl+C pour quitter)

Ensuite
   Donne l'adresse publique du serveur (ex. 141.145.12.34:6910) : elle sera inscrite dans
   le programme (liste DEFAULT_SEEDS) à la prochaine version. Tous les nouveaux PC
   s'y connecteront automatiquement au démarrage.

Sécurité du serveur
   - Ne lance jamais NumFranc en administrateur (root) : le service utilise ton compte.
   - Mets Ubuntu à jour régulièrement : sudo apt update && sudo apt upgrade
   - N'ouvre que le port 6910 (et SSH si besoin, protégé par une clé).
