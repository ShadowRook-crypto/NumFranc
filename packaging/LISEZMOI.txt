NumFranc (NFR) — mode d'emploi
==============================

1. INSTALLER ET LANCER (English: see README-EN.txt)
   Le plus simple : le fichier d'installation de votre système, sur la page des versions
   (https://github.com/ShadowRook-crypto/NumFranc/releases/latest). Ouvrez le dossier « Téléchargements », puis :
   - Mac     : double-clic sur NumFranc-macos.dmg ; glissez NumFranc vers Applications ; ouvrez-le depuis le Launchpad.
               La toute première fois, macOS affiche « n'a pas été ouvert » (projet indépendant, sans compte développeur Apple).
               Clique sur « Terminé », puis Réglages Système > Confidentialité et sécurité, tout en bas :
               « Ouvrir quand même » (mot de passe du Mac), puis « Ouvrir ». Une seule fois.
               (macOS 14 et plus ancien : clic droit sur NumFranc > Ouvrir > Ouvrir suffit.)
   - Windows : double-clic sur NumFranc-windows-installation.exe, puis « Suivant ». Si Windows affiche
               « Windows a protégé votre ordinateur » : Informations complémentaires > Exécuter quand même.
               NumFranc est ensuite dans le menu Démarrer.
   - Linux   : double-clic sur NumFranc-linux-amd64.deb (ou -arm64.deb), puis « Installer »
               (ou : sudo apt install ./NumFranc-linux-amd64.deb). NumFranc est dans le menu des applications.
   Au premier lancement, NumFranc se range tout seul dans le menu des applications et active les liens de paiement nfr:.

   Sans installeur (ce dossier, NumFranc.zip) :
   - Mac     : double-clic sur « Lancer NumFranc.command ». La 1re fois, macOS le bloque : Réglages Système >
               Confidentialité et sécurité > « Ouvrir quand même » (macOS 14 et plus ancien : clic droit > Ouvrir).
   - Windows : double-clic sur « Lancer NumFranc.bat ».
   - Linux   : dans un terminal, ./lancer-numfranc.sh
   Si aucune version toute prête n'est fournie pour votre machine, le lanceur installe
   Rust et compile NumFranc automatiquement (une seule fois, quelques minutes).

2. AU PREMIER LANCEMENT
   Une fenêtre s'ouvre (option --console pour rester en mode texte).
   Vous choisissez DEUX secrets différents :
   - le MOT DE PASSE D'OUVERTURE (12 caractères minimum), demandé à chaque démarrage :
     il permet de voir le solde, de miner et de recevoir ;
   - le CODE DE DÉPENSE (16 caractères minimum), demandé à chaque envoi :
     il protège la clé secrète elle-même. Le plus sûr : 4 ou 5 mots au hasard
     avec un chiffre et un symbole (ex. Girafe#Tambour-Nuage7).
   Le portefeuille est chiffré deux fois (AES-256-GCM puis XChaCha20-Poly1305),
   avec des clés tirées des mots de passe par Argon2id (256 Mio pour l'ouverture,
   1 Gio et 4 passes pour le code de dépense : chaque essai d'un voleur coûte cher).
   Les mots de passe ne sont enregistrés nulle part, même chiffrés.
   Puis le CODE DE SECOURS s'affiche en 3 MORCEAUX : recopiez chacun sur un papier
   différent, rangé dans un endroit différent. 2 morceaux sur 3 suffisent pour tout
   récupérer (même si vous oubliez vos mots de passe) ; un seul morceau ne sert à rien.
   Un ancien portefeuille (v0.2, v0.3) est conservé : NumFranc vous demande simplement
   de choisir vos mots de passe pour le chiffrer.
   Le minage démarre tout seul, sur la moitié des cœurs de l'ordinateur.
   Le minage utilise 4 Mio de mémoire par cœur (algorithme Argon2d) : un PC ordinaire
   reste compétitif face aux machines spécialisées. Il chauffe l'ordinateur : tapez
   « minage off » pour l'arrêter, ou lancez avec --coeurs 1 pour le ralentir.

3. REJOINDRE LE RÉSEAU
   Rien à régler : NumFranc trouve les autres ordinateurs tout seul (réseau local, puis annuaire mondial),
   et il demande lui-même à votre box d'ouvrir le port 6910 (UPnP, NAT-PMP, PCP) pour que les autres
   puissent aussi se connecter à vous. L'état s'affiche sur l'accueil et dans Réglages > Connexion, avec,
   si ça ne marche pas, la raison et quoi faire (UPnP désactivé sur la box, adresse Internet partagée par
   l'opérateur, etc.). Même sans ouverture du port, NumFranc fonctionne : il se connecte aux autres.
   Pour ajouter un nœud à la main : écrivez son adresse dans noeuds.txt (ex. monnoeud.fr:6910, dans ce dossier
   ou dans le dossier des données), ou tapez dans NumFranc :  connecter monnoeud.fr:6910
   Au démarrage, le minage attend 20 secondes et rattrape la chaîne des autres avant de miner.

4. LA FENÊTRE (français ou anglais)
   L'essentiel : Accueil (solde, minage, réseau, graphique des gains sur 7 ou 30 jours),
   Envoyer, Recevoir (adresse, empreinte, QR code), Historique (export en tableur CSV),
   Carnet d'adresses, Réglages ; et dans « Plus… » : Sécurité (code de secours,
   changement des mots de passe) et Explications (mode pas à pas).
   Le MODE EXPERT (Réglages) ajoute : Explorateur (chaque bloc, ses paiements et messages publics),
   Émission (combien de NFR existent, combien restent, paliers à venir),
   Avancé (gel, paiements annulables, pseudos, groupes à plusieurs signatures,
   preuve de réserve, demande de paiement, démarrage automatique) et Réseau.
   Réglages : langue, thème clair ou sombre, couleur, minage selon un horaire nuit/jour,
   vérification des mises à jour, mode expert, ajout de NumFranc au menu des applications.
   EMPREINTE : chaque adresse a une empreinte de 4 mots + une couleur
   (ex. « jasmin gorille horloge jonque — rouge »). Vérifiez-la avec la personne
   (par téléphone par exemple) avant d'enregistrer son adresse : un virus peut
   remplacer une adresse copiée. NumFranc prévient si une adresse n'est pas dans le carnet.

5. COMMANDES DU MODE TEXTE (lancement avec --console, tapez « aide »)
   statut, solde, adresse, adresse neuve, envoyer, historique, pairs, minage on/off, secours, quitter
   et, depuis la v0.6 : emission, gel, degel, protection, retenus, annuler, pseudos, pseudo,
   groupe, preuve, demande, demarrage (la commande « aide » les décrit toutes).

   Recevoir : « adresse » affiche votre adresse permanente (NFR1-XXXX-...). Elle ne change jamais :
              donnez-la à tout le monde. « adresse neuve » en crée une à usage unique.
   Envoyer  : envoyer NFR1-XXXX-... 12,5
   Avec une date de déblocage : envoyer NFR1-XXXX-... 5 verrou 30j
              (min = minutes, h = heures, j = jours, sem, mois, an ; maximum 10 ans).
              C'est une vraie date de calendrier : les fonds sont gelés pour le destinataire
              jusqu'à cette date (environ 1 h de marge), et personne ne peut les débloquer avant.
              Envoyé à votre propre adresse, c'est un coffre-fort.
   Avec un message : envoyer NFR1-XXXX-... 5 message Bon anniversaire !
              Le message est PUBLIC et gravé à vie dans la chaîne (140 octets maximum,
              les accents comptent double). N'y mettez rien de privé.
   Les deux ensemble : envoyer NFR1-XXXX-... 5 verrou 30j message Pour tes 16 ans

   Carnet : carnet, carnet ajouter NOM ADRESSE, carnet retirer NOM ;
   envoyer accepte un nom du carnet : envoyer Maman 5
   Sécurité : secours (3 morceaux), motdepasse (changer les deux secrets).

6. NOUVEAUTÉS DE LA v1.4.0 (protection renforcée contre les attaques à 51 %)
   - Chaînes cachées pénalisées : une chaîne minée en secret puis révélée d'un coup doit apporter beaucoup
     plus de travail pour être acceptée (pendant 2 heures).
   - Gros paiements (100 NFR et plus) : NumFranc conseille d'attendre 30 blocs au lieu de 6, et l'historique
     affiche « en cours de confirmation : x/y blocs ».

   NOUVEAUTÉS DE LA v1.3.2
   - Nouvelle présentation du projet, dans l'application, sur le site et dans les documents :
     NumFranc a l'ambition de devenir une infrastructure de paiement post-quantique de référence.

   NOUVEAUTÉS DE LA v1.3.1
   - Premier point de contrôle (bloc n°300) : l'histoire de la chaîne jusqu'à ce bloc ne peut plus être réécrite.
   - « blocs par palier » traduit dans toutes les langues ; petites corrections de textes.
   - Bibliothèque de copier-coller Windows mise à jour.

   NOUVEAUTÉS DE LA v1.3.0 (nouvelles règles du réseau, actives le 9 novembre 2026)
   Mettez NumFranc à jour avant le 9 novembre 2026 (la mise à jour automatique s'en charge) : ensuite, les
   anciennes versions ne suivent plus correctement le réseau et affichent une alerte rouge.
   - Points de contrôle : l'empreinte de blocs passés est inscrite dans NumFranc. Personne ne peut plus
     réécrire l'histoire de la chaîne avant ces blocs, même avec énormément de puissance de calcul.
   - Gardien : un paiement retenu qu'il annule revient forcément à celui qui l'avait envoyé
     (le gardien ne peut plus l'envoyer ailleurs).
   - Pseudos : les frais d'enregistrement sont détruits au lieu d'aller au mineur. Un mineur ne peut donc
     plus réserver des pseudos gratuitement en les mettant dans ses propres blocs.
   - Plus aucune pièce de moins de 0,0001 NFR dans les blocs (contre l'encombrement de la chaîne).

   NOUVEAUTÉS DE LA v1.2.3 (version de sécurité : audit complet du code)
   - Réseau : un nœud malveillant ne peut plus saturer la mémoire (taille maximale par type de message),
     ni bloquer les connexions (délai de 30 s pour se présenter), ni ouvrir des milliers de connexions.
     Les blocs déjà refusés sont reconnus tout de suite, et une petite chaîne fabriquée en secret ne peut
     plus remplacer la vraie au démarrage du réseau.
   - Portefeuille : la protection des gros paiements (seuil, délai, gardien) ne peut plus être changée
     sans votre code de dépense ; si le fichier a été modifié par quelqu'un d'autre, NumFranc refuse d'envoyer.
     Les adresses de monnaie rendue sont revérifiées avant chaque envoi.
   - Montants minuscules (moins de 0,0001 NFR) : plus relayés, pour éviter d'encombrer la chaîne.
   - Mise à jour automatique : tout est revérifié juste avant l'installation, une ancienne liste signée
     ne peut plus cacher une alerte de sécurité, et l'alerte rouge reste active même sans Internet.
   - « Toujours allumé » refuse de s'installer depuis une clé USB, un dossier temporaire ou Téléchargements.
   - Export CSV de l'historique : un message piégé ne peut plus lancer de formule dans Excel.

   NOUVEAUTÉS DE LA v1.2.2
   - Mise à jour automatique : NumFranc vérifie tout seul au démarrage puis toutes les 6 heures. Une nouvelle
     version est téléchargée puis vérifiée deux fois (signature de l'auteur, puis empreinte SHA3 du fichier) ;
     un bandeau « Installer et relancer » apparaît en haut : un clic, et NumFranc se remplace et redémarre.
     (Linux : le mot de passe de l'ordinateur est demandé. Lancé depuis le dossier téléchargé : seulement la page.)
   - Alerte de sécurité : si l'auteur signale une faille, les versions concernées affichent un bandeau rouge
     et bloquent les envois de NFR jusqu'à la mise à jour (recevoir et miner continuent).
   - Le nœud d'amorçage de la v1.2.1 est retiré : les nouveaux trouvent le réseau par l'annuaire mondial,
     maintenant interrogé toutes les 30 secondes au démarrage.

   NOUVEAUTÉS DE LA v1.2.1
   - Premier nœud d'amorçage (retiré en v1.2.2). Un nouvel ordinateur s'y connecte en quelques secondes,
     puis trouve les autres tout seul (annuaire mondial, échanges d'adresses).
   - Un même ordinateur de votre maison n'apparaît plus plusieurs fois dans les pairs connectés.
   - Le voyant vert « un autre nœud s'est connecté à toi depuis Internet » ne compte plus vos propres ordinateurs.

   NOUVEAUTÉS DE LA v1.2.0 (contient aussi tout ce qui suit : v1.1.2 et v1.1.1)
   - « Toujours allumé » (Mac, Windows, Linux) : au premier lancement, NumFranc demande « Garder NumFranc
     allumé en permanence ? (recommandé) ». Si oui :
       • il démarre avec l'ordinateur et se relance tout seul s'il s'arrête, plante ou se fige ;
       • fermer la fenêtre ne l'arrête plus : il continue en arrière-plan, garde le réseau et mine vers
         votre adresse de réception. Votre portefeuille reste fermé et chiffré, aucun mot de passe n'est gardé ;
       • quand vous rouvrez la fenêtre, elle reprend la main ; un seul NumFranc tourne à la fois.
     À changer à tout moment : Réglages > Toujours allumé. Les cœurs (jour et nuit) se règlent au même endroit.
     Sur Mac, macOS affiche « Éléments ajoutés à l'ouverture » : c'est normal (c'est le gardien de NumFranc).
   - La case « Miner avec cet ordinateur » est maintenant retenue d'un lancement à l'autre.

   NOUVEAUTÉS DE LA v1.1.2
   - Nœud permanent sous Linux en une commande : sudo numfranc --installer-serveur NFR1-…
     Il démarre avec l'ordinateur, se relance tout seul après un arrêt, un plantage ou un blocage
     (chien de garde), empêche la mise en veille et mine vers ton adresse sans garder de clé secrète.
     Voir SERVEUR.txt.

   - Mac : instructions corrigées pour macOS Sequoia (Réglages Système > Confidentialité et sécurité > « Ouvrir quand même »).

   NOUVEAUTÉS DE LA v1.1.0

     NumFranc-linux-amd64.deb / -arm64.deb (Linux). Plus besoin de terminal.

   - Ouverture automatique du port sur la box (UPnP, NAT-PMP, PCP, renouvelée toutes les 10 minutes), avec un
     message d'état clair sur l'accueil et dans Réglages > Connexion.
   - Lien de paiement nfr: : le montant arrive maintenant correctement dans « Envoyer » (« invalid amount » corrigé).

   - Réseau : un pair dont l'horloge est décalée n'est plus exclu 24 h ; un pair lent ne bloque plus la diffusion

   - Windows : les outils du système (reg, powershell, curl) sont appelés par leur chemin complet.
   - Aucun changement de chaîne ni de portefeuille : les v0.7, v1.0 et v1.1 se parlent.

7. CORRECTIONS DE LA v1.0.1
   - Portefeuille : un ancien portefeuille (importé d'une vieille version) pouvait faire planter
     le minage environ 30 secondes après le démarrage. Corrigé ; aucun fonds n'était en danger.
   - Linux : la fenêtre s'ouvre enfin (le programme utilise maintenant les bibliothèques d'affichage du système).
   - Mac : l'app NumFranc contient désormais le vrai programme. macOS la garde ouverte et lui
     envoie les liens nfr:… ; elle se met à jour toute seule quand vous installez une nouvelle version.
     Après la mise à jour, cliquez UNE fois sur « Ajouter NumFranc au menu des applications » (Réglages).

8. NOUVEAUTÉS DE LA v1.0.0
   - Nouveau logo, et une fenêtre plus simple : 6 onglets, le reste dans « Plus… » ou le mode expert.
   - Liens de paiement cliquables : un clic sur un lien nfr:… ouvre NumFranc sur « Envoyer », déjà rempli
     (rien n'est envoyé sans votre vérification et votre code de dépense). Pour l'activer, cliquez une fois
     sur « Ajouter NumFranc au menu des applications » (Réglages).
   - Bouton « Vérifier les mises à jour » : une nouvelle version n'est proposée que si sa signature est valide.
   - Compilation reproductible : chacun peut recompiler et obtenir exactement le même programme.
   - Sécurité du réseau renforcée après un audit (comme Bitcoin) : un pair doit prouver ce qu'il annonce,
     les abus sont limités et déconnectés, l'annuaire des pairs résiste à l'empoisonnement.
   - Deux règles de consensus ajoutées, actives à partir du 19 octobre 2026 (anti « time warp », champ
     locktime à 0). Elles ne changent rien aux blocs déjà minés ; mettez quand même à jour vos nœuds.
   - Aucun changement de chaîne ni de portefeuille : les v0.7 et v1.0.0 se parlent.

9. NOUVEAUTÉS DE LA v0.6
   - Pseudos : « alice.nfr » à la place de l'adresse de 77 caractères (inscrit dans la chaîne ;
     frais uniques : 100 NFR pour 3 lettres, 25 pour 4, 5 pour 5 à 7, 1 à partir de 8).
     Dans Envoyer, on peut écrire le pseudo, une adresse, un nom du carnet ou un lien nfr:….
   - Délai d'annulation : au-dessus d'un montant choisi, un paiement est retenu pendant un délai
     (de 1 s à 30 jours) ; vous (ou un gardien) pouvez l'annuler, le destinataire pas encore le dépenser.
   - Multi-signature M sur N (ex. 2 sur 3) : groupes à plusieurs clés, avec propositions à signer à tour de rôle.
   - Gel du portefeuille : la clé secrète est effacée de l'ordinateur ; dégel avec les trois codes
     (mot de passe d'ouverture, nouveau code de dépense, 2 morceaux de secours).
   - Demande de paiement (lien nfr:… et QR code), preuve de réserve, tableau de bord de l'émission,
     mode explication, démarrage automatique (fenêtre réduite), verrou « une seule copie ouverte ».
   - NOUVELLE CHAÎNE : le format des transactions a changé (protocole 4). NumFranc met tout seul
     l'ancienne chaîne de côté (fichier blocks.ancien) et repart de zéro. Votre portefeuille est conservé.
     Tous les nœuds du réseau doivent passer à la v0.6 ; une v0.5 ne peut plus se connecter.
   - Le fichier du portefeuille passe au format 04 à la première ouverture : une v0.5 ne pourra plus le lire.
     Faites une copie de wallet.dat avant la mise à jour si vous voulez pouvoir revenir en arrière.

10. BON À SAVOIR
   - Une récompense de minage devient dépensable après 100 blocs.
   - Un paiement est considéré comme sûr après 6 blocs.
   - Les données sont dans : Mac ~/Library/Application Support/NumFranc,
     Linux ~/.numfranc, Windows %APPDATA%\NumFranc
   - Pour vérifier un installeur téléchargé (.dmg, .exe, .deb) : python3 sha3sum.py --fichier SHA3SUMS.txt NOM-DU-FICHIER
   - Vérifiez les empreintes SHA3-512 avant d'utiliser une version téléchargée :
     python3 sha3sum.py --check SHA3SUMS.txt (dans le dossier NumFranc ; tout doit afficher OK).
     La signature SHA3SUMS.txt.sig prouve que ce manifeste vient de l'auteur : vérifiez-la
     avec la clé publique cle-publique.txt (commande « verifier » de signer_version, voir README).
   - Nœud permanent (serveur toujours allumé qui se relance tout seul, peut miner vers ton adresse) : voir SERVEUR.txt.

MISE À JOUR depuis une ancienne version :
   - depuis la v0.6, la v0.7 ou la v1.0 : installez la v1.1 avec l'installeur (ou remplacez le dossier NumFranc),
     tout est conservé : portefeuille, chaîne, réglages (ils sont dans le dossier des données, pas dans le programme) ;
   - depuis la v0.5 ou avant : voir « NOUVEAUTÉS DE LA v0.6 » (nouvelle chaîne, automatique) ;
   - depuis la v0.2 (adresses NFR1-XXXX) : le portefeuille est conservé, mais la chaîne
     repart de zéro (nouvel algorithme de minage) : renommez le fichier blocks.dat
     du dossier de données en blocks-ancien.dat ;
   - depuis la v0.1 (adresses NFR1 + 128 caractères) : déplacez tout le dossier de données.
