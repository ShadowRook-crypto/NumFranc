NumFranc

La monnaie numérique pensée pour l'après-ordinateur quantique, minée par des ordinateurs ordinaires.

L'histoire

Bitcoin a montré qu'une monnaie pouvait exister sans banque. Mais il a deux faiblesses que tout le monde connaît : ses signatures pourront un jour être cassées par un ordinateur quantique, et son minage est devenu l'affaire d'usines remplies de machines spécialisées.

NumFranc est parti d'une question simple : et si on recommençait, en réglant ces deux problèmes dès le premier bloc ? Chaque paiement est signé avec ML-DSA, le standard post-quantique choisi par le NIST en 2024. Et chaque essai de minage oblige l'ordinateur à remplir et relire de la mémoire, ce qui rend les machines spécialisées presque inutiles : le PC de votre chambre compte autant que celui d'une usine.

Le logo raconte cette histoire : six bandes bleues et rouges qui tournent autour d'un hexagone, chacune passant le relais à la suivante, comme les blocs d'une chaîne qui s'ajoutent l'un après l'autre. Au centre, le « N » de NumFranc.

Ce qui le rend différent

Post-quantique dès le départ

Signatures ML-DSA-87 (niveau 5 du NIST) et empreintes SHA3-512.

Minage pour tous

Algorithme Argon2d gourmand en mémoire : un ordinateur ordinaire reste compétitif.

Messages et coffres

Un message joint à chaque paiement, et des fonds verrouillés jusqu'à une vraie date de calendrier.

Adresses lisibles

Une adresse permanente de 77 caractères et son empreinte de 4 mots pour éviter les erreurs.

Portefeuille blindé

Chiffré deux fois, un code séparé pour dépenser, et un code de secours en 3 morceaux (2 suffisent).

Sans serveur central

Les ordinateurs se trouvent tout seuls, sur le réseau local comme à l'autre bout du monde.

Télécharger et installer

Choisissez votre ordinateur. Pas de terminal, pas de commande : on double-clique, c'est tout.

Mac

Télécharger pour Mac
  1. Dans « Téléchargements », double-clic sur NumFranc-macos.dmg.
  2. Une fenêtre s'ouvre avec une flèche : glissez NumFranc vers Applications.
  3. Ouvrez NumFranc depuis le Launchpad, comme n'importe quelle app.
La toute première fois, macOS peut dire que l'app « ne peut pas être ouverte » (projet indépendant, sans compte développeur Apple) : clic droit sur NumFranc > Ouvrir > Ouvrir. Une seule fois.

Windows

Télécharger pour Windows
  1. Dans « Téléchargements », double-clic sur NumFranc-windows-installation.exe.
  2. Cliquez sur « Suivant », puis « Terminer ».
  3. NumFranc est dans le menu Démarrer.
Windows peut afficher « Windows a protégé votre ordinateur » (nous n'achetons pas de certificat payant) : cliquez sur Informations complémentaires puis Exécuter quand même.

Linux

Télécharger (PC) Télécharger (ARM)
  1. Double-clic sur le fichier .deb dans votre gestionnaire de fichiers (Ubuntu, Debian, Mint…).
  2. Cliquez sur « Installer ».
  3. Ouvrez NumFranc depuis le menu des applications.
En ligne de commande : sudo apt install ./NumFranc-linux-amd64.deb

Au premier lancement

  1. Choisissez vos deux mots de passe, et recopiez les 3 morceaux de votre code de secours sur 3 papiers séparés.
  2. NumFranc range tout seul son icône dans le menu et active les liens de paiement nfr:.
  3. Il ouvre tout seul le port sur votre box et cherche les autres ordinateurs : l'état est dans Réglages > Connexion.
  4. Votre ordinateur rejoint le réseau et commence à miner.

Pour les curieux : chaque version est signée avec une clé post-quantique (SLH-DSA). La liste des empreintes SHA3SUMS.txt et sa signature SHA3SUMS.txt.sig sont sur la page des versions, avec la clé publique : 5e1d1c80fdd07d3bc4095f45a05649fc006bce347609b1566b3c25e940881736. Le dossier NumFranc.zip contient aussi le code et un outil de vérification.
